# Smart Home Budget & Expense Categorizer: Proposal (қазақша)

CSS4007 қорытынды жобасы. Топ: [Аты 1], [Аты 2], [Аты 3].

## 1. Мәселе және идея
Көп адам ақшасының қайда кететінін білмейді. Банк көшірмелері CSV/PDF түрінде келеді, ал шығындарды қолмен бөлу жалықтырады. Біз жеке қаржылық көмекші жасаймыз: пайдаланушы көшірмені жүктейді, жүйе әр транзакцияны категорияға бөледі, әдеттен тыс шығындарды белгілейді және келесі айға түсіндірмесі бар бюджет ұсынады.

## 2. Негізгі функциялар
1. **Ingestion.** CSV/PDF көшірмелерді (Kaspi, Halyk, жалпы CSV) бірыңғай схемаға келтіру. Жеке деректер LLM-ге дейін маскаланады.
2. **Гибридті категоризация.** Алдымен ережелер, танылмағандары LLM-ге батчпен, нәтиже мерчант бойынша кэштеледі.
3. **Аномалия табу.** Медиана/MAD немесе IQR, жаңа мерчант, қайталанған төлем. LLM тек түсіндіреді.
4. **Бюджет ұсынысы.** Тұрақты және өзгермелі шығындар бөлек, лимит 3 айдың медианасынан, LLM негіздемесімен.
5. **Веб-интерфейс.** Streamlit.

## 3. AI компоненті
- Категоризация мен түсіндірмеге құрылымды шығыс беретін LLM.
- Tool-use пайплайн: арифметиканы LLM емес, детерминді функциялар орындайды.
- Модель: тегін API (Gemini/Groq) немесе локалды Ollama.

## 4. Бағалау жоспары
| Компонент | Әдіс | Метрика |
|---|---|---|

Python, pandas, SQLite, pdfplumber, Streamlit, pytest. **Claude Code** (ақылы, Claude Pro). CLAUDE.md стек пен ережелерді анықтайды.
